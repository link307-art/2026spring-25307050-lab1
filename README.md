 该项目为 HarmonyOS ArkTS + WebView 内嵌 Three.js + MediaPipe 手部识别混合开发应用，核心功能为摄像头手势驱动 3D 粒子特效，全部代码分为四大核心模块：module.json5 配置文件、EntryAbility 应用入口、ArkTS 页面容器 Index.ets、Web 三维交互页面 index.html，各模块构成与功能完整说明如下：
一、module.json5：模块权限与能力配置文件
代码构成
整体分为 4 个核心板块：模块基础定义、应用主 Ability 配置、相机运行时权限声明、备份扩展能力配置
基础模块信息：标记当前模块为程序入口 entry，适配手机设备，指定主启动组件为 EntryAbility；
abilities 主应用配置：注册 EntryAbility 作为程序启动入口，配置桌面图标、启动窗口参数；注册系统桌面唤起技能，支持从系统主页打开应用；
requestPermissions 权限配置：声明相机 CAMERA 运行时权限，限定仅应用前台使用时申请权限，权限绑定 EntryAbility，为网页调取摄像头实现手势识别提供系统权限支撑；
extensionAbilities 扩展能力：内置备份扩展组件 EntryBackupAbility，用于应用本地数据备份，不参与核心手势粒子交互逻辑。
核心作用
作为鸿蒙应用底层配置文件，向操作系统声明应用所需硬件权限、程序启动入口、系统唤起能力，是程序正常运行的基础配置，若无相机权限则网页无法调用摄像头完成手部识别。
二、EntryAbility.ets：鸿蒙应用生命周期入口（UIAbility）
代码构成
标准 HarmonyOS UIAbility 生命周期回调函数集合：
onCreate：应用进程创建时执行，初始化全局应用色彩模式，打印生命周期调试日志；
onWindowStageCreate：窗口创建核心逻辑，加载项目主页面 pages/Index；
onWindowStageDestroy、onDestroy、onForeground：分别对应窗口销毁、应用进程退出、应用切换至前台，仅打印调试日志，用于观测应用生命周期状态。
核心作用
鸿蒙应用的启动入口，负责创建应用顶层窗口并加载 ArkTS 页面，搭建鸿蒙原生系统层与前端 Web 交互页面的运行桥梁。
三、Index.ets：ArkTS 页面容器，承载 Web 三维网页
代码构成
仅包含单个自定义组件 ParticleVisualizer，内部核心为 Web 网页容器组件，配套权限拦截、全屏适配相关配置：
Web 组件基础参数配置：加载本地 rawfile 目录下的 index.html 网页，同步开启 JavaScript、本地 DOM 存储、外部图片加载、媒体播放全部权限；
摄像头权限拦截回调 onPermissionRequest：自动拦截 H5 网页发起的摄像头授权请求并直接放行，解决鸿蒙 WebView 默认拦截相机硬件、MediaPipe 无法采集画面的核心问题；
沉浸式全屏适配配置：扩展页面安全显示区域，Web 容器宽高铺满整个屏幕，设置透明背景实现无边界全屏展示。
核心作用
作为鸿蒙原生层与 Web 三维页面的中间载体，提供 Web 运行环境、放行网页摄像头硬件权限、全屏承载 3D 粒子交互网页，衔接鸿蒙系统硬件能力与前端三维交互逻辑。
四、index.html：Web 端核心交互层（Three.js 3D 粒子 + MediaPipe 手势识别）
本文件为项目功能实现核心，整体拆分为 6 大功能分区：HTML 布局与 CSS 样式、第三方依赖库引入、Three.js 3D 粒子渲染系统、MediaPipe 手部 AI 识别模块、UI 交互控制逻辑、全局动画渲染主循环
1. HTML & CSS：界面布局与视觉样式
页面分层结构：加载提示层、3D 粒子画布容器、右侧参数控制面板、左下角摄像头实时预览框；
视觉样式：实现玻璃拟态磨砂面板 UI，定义配色变量、按钮、颜色选择器、滑块控件样式，提供可视化粒子参数调节面板。
2. 外部 JS 三方库依赖
通过 CDN 在线引入两个核心技术库：
three.js：WebGL 三维渲染引擎，负责构建、渲染动态 3D 粒子星云场景；
MediaPipe Hands：谷歌手部识别 AI 库，读取摄像头画面，解析手部 21 个关键骨骼坐标，实现手势捕捉。
3. Three.js 3D 粒子渲染系统
初始化函数 initThree：创建三维场景、透视相机、WebGL 渲染器，生成静态星空背景粒子；
粒子生成函数 generateModel：根据选中预设（月球 / 海王星 / 冥王星 / 爱心）生成对应空间分布形态的粒子几何体；
GLSL 自定义着色器：包含顶点着色器、片元着色器，实现粒子近大远小、环形发光、色相随时间流动、透明度渐变等动态视觉特效；
材质渲染配置：采用叠加混合模式，实现粒子发光互相融合，营造通透星云视觉效果。
4. MediaPipe 手势识别模块 initMediaPipe
绑定页面 video 摄像头标签，启动设备摄像头画面采集；
加载离线手部 AI 识别模型，实时解析视频流内的手部关键点；
手势回调函数 onHandResults：识别到手掌后，读取拇指、手掌基准关键点坐标，计算手掌开合幅度、手掌旋转角度，同步更新全局粒子旋转、扩散控制参数。
5. UI 交互控制逻辑
changePreset：切换粒子空间分布预设模型，同步修改粒子基础渲染配色；
setupUIListeners：绑定页面颜色选择器、粒子密度滑块交互事件，实时修改粒子颜色、粒子总数量；
onWindowResize：窗口尺寸自适应逻辑，3D 画布跟随屏幕大小同步缩放。
6. 全局动画主循环 animate
程序持续运行的渲染循环，每一帧依次执行以下逻辑：
更新着色器时间变量，驱动粒子动态流动、色彩渐变；
平滑插值过渡手势采集到的旋转、扩散参数，消除粒子抖动；
控制背景星空缓慢自动自转；
渲染完整 3D 粒子画面，实时响应手部手势变化。
整套项目完整功能总概括
运行载体：基于 HarmonyOS 系统，使用 DevEco Studio 开发，采用原生 UIAbility+WebView 混合架构；
硬件调用：通过鸿蒙系统声明并获取相机权限，网页内直接调用设备摄像头；
AI 手势交互：MediaPipe 实时识别手掌姿态，捕捉手掌旋转、开合幅度两类手势动作；
3D 视觉渲染：依托 Three.js 构建可交互粒子星云，支持 4 种粒子形态预设、自定义粒子基础颜色、自定义粒子密度；
手势联动逻辑：手掌旋转控制全部粒子整体旋转，手掌开合控制粒子扩散范围；
可视化控制面板：内置原生 UI 调节面板，支持一键切换粒子模型、实时调整视觉参数；
渲染优化：自定义 GLSL 着色器实现粒子发光、动态渐变色彩，叠加混合渲染打造通透星云质感；
设备适配：支持沉浸式全屏显示、窗口尺寸自适应、鸿蒙 Web 自动放行相机权限，可在移动端完整运行。
